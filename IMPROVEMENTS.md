# Improvements over the original

Every deliberate departure from the 1988 DOS game is listed here, so the port's behaviour can always be traced back to the original described in [`spec/`](spec/README.md). The rules of the game are otherwise the original's, bugs included unless they are listed under [Original bugs fixed](#original-bugs-fixed).

IDs are stable: the code refers to them. Status is *done* unless marked. **Setting** means a switch restores the original behaviour. This file is the register; the specification of each departure is in part C of the spec, and [`spec/C-port/departures.md`](spec/C-port/departures.md) maps every id to its section, its level (required, optional, setting) and what remains. IMP-009 was never assigned.

## Original bugs fixed

Only bugs that destroy the player's money, items or characters are fixed. Every other known bug of the original is kept on purpose and documented where it happens (e.g. [`spec/A-games/engine/combat-rules.md`, "Known original bugs affecting combat"](spec/A-games/engine/combat-rules.md#known-original-bugs-affecting-combat)).

| ID | Fix | Original |
|---|---|---|
| IMP-028 | A payment reads all of a character's coins | Reads the value as 16 bits and loses anything above 65 535 gp ([`spec/A-games/engine/town.md`, "Money"](spec/A-games/engine/town.md#money-o-overlay-4c2d-fun_4894_28be)) |
| IMP-028 | A gem or jewel kept after appraisal is always added | Lost when the character carries no items ([`spec/A-games/engine/town.md`, "Appraise"](spec/A-games/engine/town.md#appraise-o-fun_4c2d_19b2)) |
| IMP-028 | A magic-user level with no new spell to choose leaves max HP alone | Sets max HP to 1 ([`spec/A-games/engine/chargen-and-progression.md`](spec/A-games/engine/chargen-and-progression.md)) |
| IMP-031 | Alter → Drop refuses to drop the last character | Offers to quit to DOS ([`spec/A-games/engine/camp-and-time.md`, "Alter"](spec/A-games/engine/camp-and-time.md#alter-o-fun_3f81_1c59)) |
| IMP-049 | After ROB takes items, the victims' AC, THAC0 and damage are recomputed | A stolen readied item keeps counting until something else recomputes them (`FUN_2fea_1df0`, [`spec/A-games/engine/ecl.md`](spec/A-games/engine/ecl.md), ROB) |
| IMP-075 | A computer-run caster whose random pick is a memorised slot holding a spell still to be learned (id + 0x80) turns it down and picks again | The pick's record is read past the end of the spell table (PoR DS:31FA, CotAB DS:37DC + 16·id) and the spell is begun or cast as those bytes say (`FUN_3334_0545`, CotAB 0x236CB; [`spec/A-games/engine/combat-ai.md`, "Spells and items"](spec/A-games/engine/combat-ai.md#spells-and-items-o-fun_3334_02ebc-spell-pri)) |

A switch back to the original behaviour is planned for IMP-028.

Related: IMP-034 brought the Lightning Bolt path and bounce, Stinking Cloud squares, the AI's weapon choice and the rake/hug follow-ups in line with the original, bugs included (a bolt shortened by its cumulative cost at each creature, coming straight back off a wall). Its one departure is listed under [Combat](#combat).
