# Improvements over the original

Every deliberate departure from the 1988 DOS game goes here, so the port's behaviour can always be traced back to the original described in [`spec/`](spec/README.md).

- **Status**: planned, in progress, done
- **Toggle**: whether a setting restores the original behaviour (needed for anything that changes gameplay or difficulty)

| ID | Area | Improvement | Original behaviour | Toggle | Status |
|---|---|---|---|---|---|
| IMP-001 | Exploration | Real 3D view rendered from the GEO maps, with smooth movement and turning | 88×88 view assembled from pre-drawn 8×8 tiles ([`spec/maps.md`](spec/maps.md)) | Classic view later, once its spec gap is closed | in progress |
| IMP-002 | Saving | Save anywhere: a Save button in the game's command bar writes slot A–J in the original layout (quicksave still to come) | Saving only from the camp menu and the party screen ([`spec/camp.md`](spec/camp.md)) | Yes (changes difficulty; the switch is still to be added) | in progress |
| IMP-003 | Interface | Mouse and touch for every menu and screen; in the 3D view, an on-screen movement pad and tap zones (left third turns left, middle moves, right third turns right) | Keyboard only ([`spec/graphics.md`](spec/graphics.md), menu input loop) | No | in progress |
| IMP-004 | Interface | Responsive layout keeping the original arrangement (3D view, party roster to the right, text below, command line at the bottom); on narrow screens the panels stack | Fixed 320×200 screen ([`spec/graphics.md`](spec/graphics.md), "Screen layout") | No | in progress |
| IMP-005 | Platform | Runs offline as an installable web app or a single file; game files imported once and kept in the browser | DOS executable reading files from its folder | No | in progress |
| IMP-006 | Saving | Saves exported and imported as original `SAVGAM*.DAT` files | Files in the game folder | No | planned |
| IMP-007 | Exploration | 3D scene lit with ambient and directional light, a sky colour, a grey floor and distance fog. Walls use the nearest front-wall piece of each wall type (kind 6) as a texture | Flat background bands drawn by `FUN_55a0_0174` from colours at `DS:6A60–6A63` (source of those colours not yet traced); pre-drawn walls per distance | No | in progress |
| IMP-008 | Interface | Scrollable message log: each `PRINT_CLEAR` starts a new block instead of wiping the window, and the last 120 blocks are kept; short feedback for blocked moves ("Blocked.", "Locked.") | Six-line text window that clears; a bump sound only | No | in progress |
| IMP-009 | Interface | Party roster rows are clickable: select a character, click again for the character sheet in a dialog | Character chosen with keys; separate full-screen View | No | in progress |
| IMP-010 | Interface | Script menus become buttons in the command bar (first letter still the hotkey); one-item "PRESS <RETURN> OR BUTTON TO CONTINUE" prompts become a Continue button (Enter, Space, or a tap on the view); vertical menus become a tappable list | Keyboard-driven menu line on row 24 ([`spec/ecl.md`](spec/ecl.md), HMENU/VMENU) | No | in progress |
| IMP-011 | Exploration | Script-driven moves (e.g. Rolf's tour) animate between squares instead of jumping | Each `CALL 0x2C90` redraws the new square | No | in progress |
| IMP-012 | Interface | Script pauses (opcode 0x3A, game speed × 225 ms) can be skipped with a click, a tap on the view or any key | Pauses always run to the end | No | in progress |
| IMP-013 | Sound | Effects come from the original driver data in the player's `START.EXE`, emulated tick by tick with the PC speaker, and are played without pausing the game; on/off switch | `PlaySound` busy-waits about 0.1 s while a cut-off effect plays ([`spec/sound.md`](spec/sound.md)) | Sound on/off | done |
| IMP-014 | Sound | A footstep each time an encounter sprite approaches (e.g. Rolf walking up) | `APPROACH` redraws the sprite silently | Sound on/off | in progress |
| IMP-015 | Sound | Sound device chosen in the game (PC speaker, Tandy/PCjr, off), switchable at any time; the Tandy chip is emulated (approximate noise) | Chosen once in the installer, stored in `POOL.CFG` ('P' or 'T'); Ctrl-S mutes ([`spec/sound.md`](spec/sound.md)) | Is the setting | done |
| IMP-016 | Party | Created characters are kept in browser storage (the roster), seeded once with the characters from the imported files | Each character is written to `<name>.cha/.itm/.spc` in the save directory and listed in `charlist.txt` ([`spec/menus.md`](spec/menus.md) §2.2) | No | done |
| IMP-017 | Party | Combat icon editor as one panel: head, weapon and size with arrows, each part's two colours picked from a 16-colour palette, old and new icons side by side | Nested menus (Parts / colour-1 / colour-2 / Size, then Next / Prev / Keep / Exit per part) and a closing "Is this icon ok?" ([`spec/menus.md`](spec/menus.md) §4.2) | No | done |
| IMP-018 | Party | Modify shows every ability with − / + buttons and its allowed range; arrow keys still work as in the original | A cursor moved with the cursor keys on the character sheet ([`spec/menus.md`](spec/menus.md) §4.1) | No | done |
| IMP-019 | Party | Load saved game is always available on the party screen and lists both browser saves and the saves that came with the game files | Load is enabled only while the party is empty ([`spec/menus.md`](spec/menus.md) §2) | No | done |
| IMP-020 | Exploration | Encounter sprites stand in the 3D scene, a little beyond the centre of their square, and never beyond the first wall in view (scripts count an open door as passable, so an encounter can be set two squares away, behind a door); when that wall is close, distances 0–2 are spread over the room in front of it so each step still shows. The nearest (most detailed) frame is used at every distance at one world size, and perspective shrinks it | A smaller frame per distance, drawn at a fixed spot in the pre-drawn 88-pixel view ([`spec/graphics.md`](spec/graphics.md), "Encounter sprites"); that spot does not line up with the 3D view's floor | No | done |
| IMP-021 | Exploration | An encounter sprite stepping closer (`APPROACH`, or ADVANCE in the encounter menu) glides to its new place over 0.45 s | The sprite is redrawn with the next larger frame in one go | No | done |
| IMP-022 | Interface | The area map is always on screen, under the party roster (beside it on narrow screens), updated on every move; click it for the large view. It shows the whole 16 × 16 map, with open doors and locked doors in their own colours. Where the original refuses the map, the panel says "Not here." | Area toggles an overhead map in place of the 3D view: an 11 × 11 window round the party, walls only (doors drawn as walls), no fog of war; "Not Here." while ECL 0x49FB is set ([`spec/maps.md`](spec/maps.md), "Overhead map") | No | done |
| IMP-023 | Interface | Commissions panel (command bar): each commission the clerk has offered, as open, summoned (who to see), reward due, failed or closed; one-off deeds once earned; the unpaid graveyard bounty; and the proclamation numbers once the City Hall wall has been read. A dot on the button when a reward or summons is waiting. Offers seen are kept with browser saves; for other saves, anything under way in the game's variables is listed | No quest log: only the City Clerk reports rewards and repeats the open offers, and the proclamations are numbers to look up in the printed journal ([`spec/commissions.md`](spec/commissions.md)) | No | done |
| IMP-024 | Interface | Landmark icons on the area map (shops, temples by god, inn, taverns, City Hall, harbour, training halls, gateway), with the square's text as a tooltip and a legend on the large map. Found by reading the area's script: what each square's event handler does (shop and temple flags, rest, training, its text, or where its door leads) | The overhead map shows walls only ([`spec/maps.md`](spec/maps.md), "Overhead map"); the printed manual has a map of New Phlan | No | done |
